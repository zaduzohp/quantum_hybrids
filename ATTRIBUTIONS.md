# Third-party code in this repository

Every file under `src/qsocket/vendored/` is a copy of code written elsewhere. This file
is the inventory: what was copied, from where, at which commit, under which licence, and
what was changed. The per-file headers say the same thing at the point of use; this file
exists so that the answer is available without reading eight headers.

Nothing outside `src/qsocket/vendored/` is third-party code.

**Why this is permitted.** Apache-2.0 §2 grants the right to reproduce, prepare
derivative works of, and distribute the Work in Source form. The conditions of §4 are met
as follows:

- **§4(a)** a copy of the Licence travels with the work —
  `src/qsocket/vendored/LICENSE-Apache-2.0.txt`;
- **§4(b)** modified files carry a prominent notice of change — each copied file states
  `Changes vs upstream: none — verbatim copy, this header is the only addition`;
- **§4(c)** all copyright, patent, trademark and attribution notices from the Source form
  are retained — the Apache header block and the Xanadu copyright line are reproduced
  unaltered at the top of every copied file;
- **§4(d)** does not apply: **the upstream repository contains no `NOTICE` file**
  (checked against the repository root of `XanaduAI/qml-benchmarks`).

Equivalence with upstream is verified rather than asserted: the same parameter grid,
generated by the upstream package in a separate virtual environment and by these copies,
yields 16 arrays identical bit-for-bit (399,000 numbers, zero differences). The digests
from that run are pinned in `tests/test_vendored_generators.py`.

### How to cite

The generators come from the study this repository benchmarks against, so **cite the
paper and the software separately**:

```bibtex
@article{bowles2024benchmarking,
  author  = {Bowles, Joseph and Ahmed, Shahnawaz and Schuld, Maria},
  title   = {Better than classical? The subtle art of benchmarking
             quantum machine learning models},
  journal = {arXiv preprint arXiv:2403.07059},
  year    = {2024},
}

@software{qmlbenchmarks,
  author  = {Bowles, Joseph and Ahmed, Shahnawaz and Schuld, Maria},
  title   = {qml-benchmarks},
  version = {commit 95e5a07e8e9e75ba7e24e67fb32b030112a1309a},
  license = {Apache-2.0},
  url     = {https://github.com/XanaduAI/qml-benchmarks},
}
```

The upstream README offers no citation format of its own; the software entry above
follows the usual convention of naming the exact commit, because the dataset manifests
record the vendoring commit rather than a package version.

## 2. QC1 — Quantum Banknote Classifier on ODRA 5 — first-party

| | |
|---|---|
| Upstream | `QC1_Quantum_Banknote_Classifier_on_ODRA_5` — an earlier project of the same student research group, not public |
| Commit | `8855e2ec99bdc39b5b94dec0b18ea87b9fd50fe9` ("KL Done", 2026-07-19) |
| Licence | **the upstream repository carries no `LICENSE` file** |

| file here | upstream path | what was taken |
|---|---|---|
| `src/qsocket/vendored/circuit_stats.py` | `qbanknote/circuit_stats.py` | the whole module |
| `src/qsocket/vendored/counts.py` | `qbanknote/metrics.py` | `bitstring_qubit_value`, `qubit_expectation_from_counts` |
| `src/qsocket/vendored/entanglement.py` | `qbanknote/metrics.py` | `single_qubit_reduced_density`, `meyer_wallach_score` |
| `src/qsocket/vendored/expressibility.py` | `qbanknote/metrics.py` | `haar_pdf_fidelity`, `binned_distributions`, `kl_divergence`, `sample_haar_fidelities` |

`tests/test_vendored_counts.py` and `tests/test_vendored_metrics_cls.py`.
